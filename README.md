# Rayhan Kabir — Personal Portfolio

A responsive, light-theme personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and dynamic footer year

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

For local development, you can also run a simple server from this folder:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Before publishing
- Confirm the current job title and employment dates.
- Verify certification names and credential status.
- Add approved project diagrams, screenshots, sanitized configs and measurable outcomes.
- Add a downloadable CV if desired.
- Replace or supplement the project summaries with case studies you can publicly share.

## Deployment
The static site can be hosted on GitHub Pages, Netlify, Vercel or a standard web host. No build step is required.
